Text Studio

Join, split, case, and clean text values in the Sheet.

Core pack — always on.

Each function below shows Sample input → Formula → Result (or Illustrative result when values can vary).

Functions​

CONCAT​

Join text values.

Signature: CONCAT(text...)

Sample input

AB
1FirstLast
2MayaChen

Formula (cell C2): =CONCAT(A2, " ", B2)

Result: Maya Chen

CONCATENATE​

Join text values (classic alias of joining arguments).

Signature: CONCATENATE(text...)

Sample input

AB
1CityRegion
2AustinTX

Formula (cell C2): =CONCATENATE(A2, ", ", B2)

Result: Austin, TX

TEXTJOIN​

Join with a delimiter, optionally skipping blanks.

Signature: TEXTJOIN(delimiter, ignore_empty, text...)

Sample input

ABC
1Tag1Tag2Tag3
2espressooat

Formula (cell D2): =TEXTJOIN(", ", TRUE, A2:C2)

Result: espresso, oat

LEFT​

Leftmost characters.

Signature: LEFT(text, [num_chars])

Sample input

AB
1Employee ID
2EMP-10482

Formula (cell B2): =LEFT(A2, 3)

Result: EMP

RIGHT​

Rightmost characters.

Signature: RIGHT(text, [num_chars])

Sample input

AB
1Invoice
2INV-2024-091

Formula (cell B2): =RIGHT(A2, 3)

Result: 091

MID​

Substring by start position and length.

Signature: MID(text, start, num_chars)

Sample input

AB
1SKU
2CAF-LATTE-12oz

Formula (cell B2): =MID(A2, 5, 5)

Result: LATTE

LEN​

Character count.

Signature: LEN(text)

Sample input

AB
1Name
2Maya Chen

Formula (cell B2): =LEN(A2)

Result: 9

LOWER​

Lowercase.

Signature: LOWER(text)

Sample input

AB
1Role
2Barista Lead

Formula (cell B2): =LOWER(A2)

Result: barista lead

UPPER​

Uppercase.

Signature: UPPER(text)

Sample input

AB
1Code
2tx-austin

Formula (cell B2): =UPPER(A2)

Result: TX-AUSTIN

PROPER​

Title-case words.

Signature: PROPER(text)

Sample input

AB
1Customer
2maya chen

Formula (cell B2): =PROPER(A2)

Result: Maya Chen

TRIM​

Collapse extra spaces (leading, trailing, and repeated).

Signature: TRIM(text)

Sample input

AB
1Raw name
2Maya Chen

Formula (cell B2): =TRIM(A2)

Result: Maya Chen

CLEAN​

Remove non-printable characters.

Signature: CLEAN(text)

Sample input

AB
1Status
2Paid

Formula (cell B2): =CLEAN(CHAR(7)&A2)

Result: Paid

FIND​

Case-sensitive position of text within text (1-based).

Signature: FIND(find_text, within_text, [start_num])

Sample input

AB
1Email
2maya@cafe.example

Formula (cell B2): =FIND("@", A2)

Result: 5

SEARCH​

Case-insensitive position of text within text (1-based).

Signature: SEARCH(find_text, within_text, [start_num])

Sample input

AB
1Label
2Oat Milk Latte

Formula (cell B2): =SEARCH("milk", A2)

Result: 5

REPLACE​

Replace characters by position.

Signature: REPLACE(old_text, start_num, num_chars, new_text)

Sample input

AB
1Phone
2555-0100

Formula (cell B2): =REPLACE(A2, 1, 3, "800")

Result: 800-0100

SUBSTITUTE​

Replace occurrences of a string.

Signature: SUBSTITUTE(text, old_text, new_text, [instance_num])

Sample input

AB
1Path
2cafe/menu/latte

Formula (cell B2): =SUBSTITUTE(A2, "/", "-")

Result: cafe-menu-latte

REPT​

Repeat text.

Signature: REPT(text, number_times)

Sample input

AB
1StarsCount
2★3

Formula (cell C2): =REPT(A2, B2)

Result: ★★★

EXACT​

Case-sensitive equality (TRUE / FALSE).

Signature: EXACT(text1, text2)

Sample input

AB
1EnteredStored
2Mayamaya

Formula (cell C2): =EXACT(A2, B2)

Result: FALSE

TEXT​

Format a value as text.

Signature: TEXT(value, format_text)

Sample input

AB
1Amount
212.5

Formula (cell B2): =TEXT(A2, "$#,##0.00")

Result: $12.50

VALUE​

Parse text to a number.

Signature: VALUE(text)

Sample input

AB
1Price text
24.50

Formula (cell B2): =VALUE(A2)

Result: 4.5

NUMBERVALUE​

Convert locale-formatted numeric text to a number.

Signature: NUMBERVALUE(text, [decimal_separator], [group_separator])

Sample input

AB
1EU amount
21.234,56

Formula (cell B2): =NUMBERVALUE(A2, ",", ".")

Result: 1234.56

DOLLAR​

Format a number as currency text.

Signature: DOLLAR(number, [decimals])

Sample input

AB
1Total
21234.5

Formula (cell B2): =DOLLAR(A2)

Result: $1,234.50

FIXED​

Format a number with a fixed number of decimals (as text).

Signature: FIXED(number, [decimals], [no_commas])

Sample input

AB
1Total
21234.567

Formula (cell B2): =FIXED(A2, 2)

Result: 1,234.57

T​

Return text values unchanged; return blank for non-text values.

Signature: T(value)

Sample input

AB
1LabelQty
2Latte3

Formula (cell C2): =T(A2)

Result: Latte

N​

Convert a value to its numeric representation (TRUE→1, text→0, numbers unchanged).

Signature: N(value)

Sample input

AB
1Flag
2TRUE

Formula (cell B2): =N(A2)

Result: 1

CHAR​

Character from a code point (ANSI / Windows-1252 style codes in classic sheets).

Signature: CHAR(number)

Sample input

AB
1Code
265

Formula (cell B2): =CHAR(A2)

Result: A

CODE​

Code of the first character.

Signature: CODE(text)

Sample input

AB
1Letter
2A

Formula (cell B2): =CODE(A2)

Result: 65

UNICHAR​

Return a Unicode character from a code point.

Signature: UNICHAR(number)

Sample input

AB
1Code point
29733

Formula (cell B2): =UNICHAR(A2)

Result: ★

UNICODE​

Return the Unicode code point of a character.

Signature: UNICODE(text)

Sample input

AB
1Glyph
2★

Formula (cell B2): =UNICODE(A2)

Result: 9733

TEXTBEFORE​

Return text before a delimiter.

Signature: TEXTBEFORE(text, delimiter, [instance_num])

Sample input

AB
1Email
2maya@cafe.example

Formula (cell B2): =TEXTBEFORE(A2, "@")

Result: maya

TEXTAFTER​

Return text after a delimiter.

Signature: TEXTAFTER(text, delimiter, [instance_num])

Sample input

AB
1Email
2maya@cafe.example

Formula (cell B2): =TEXTAFTER(A2, "@")

Result: cafe.example

TEXTSPLIT​

Split text into rows or columns by delimiter.

Signature: TEXTSPLIT(text, col_delimiter, [row_delimiter])

Sample input

AB
1Tags
2coffee,tea,pastry

Formula (cell B2): =TEXTSPLIT(A2, ",")

Result: spills coffee | tea | pastry across B2:D2

ARRAYTOTEXT​

Convert an array to a text representation.

Signature: ARRAYTOTEXT(array, [format])

Sample input

ABC
1AMPMLate
2352

Formula (cell D2): =ARRAYTOTEXT(A2:C2)

Result: 3, 5, 2

VALUETOTEXT​

Convert a value to text.

Signature: VALUETOTEXT(value, [format])

Sample input

AB
1Qty
212

Formula (cell B2): =VALUETOTEXT(A2)

Result: 12

ASC​

Convert full-width (double-byte) characters to half-width (single-byte) characters.

Signature: ASC(text)

Sample input

AB
1Full-width digits
2１２３

Formula (cell B2): =ASC(A2)

Result: 123
