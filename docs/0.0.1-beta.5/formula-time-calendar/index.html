Calendar & Time

Dates, times, and calendar arithmetic for schedules and reporting.

Core pack — always on.

Each function below shows Sample input → Formula → Result (or Illustrative result when values can vary).

Functions​

TODAY​

Return the current date (date only; refreshes when the sheet recalculates).

Signature: TODAY()

Sample input

(none — volatile)

Formula (cell A1): =TODAY()

Illustrative result: 8/12/2026 (always today’s date; display depends on cell format)

NOW​

Return the current date and time.

Signature: NOW()

Sample input

(none — volatile)

Formula (cell A1): =NOW()

Illustrative result: 8/12/2026 16:05 (varies by clock and format)

DATE​

Create a date from year, month, and day values.

Signature: DATE(year, month, day)

Sample input

ABC
1YearMonthDay
22024315

Formula (cell D2): =DATE(A2, B2, C2)

Result: 3/15/2024 (serial 45366 with General format)

TIME​

Create a time from hour, minute, and second values.

Signature: TIME(hour, minute, second)

Sample input

ABC
1HourMinuteSecond
214300

Formula (cell D2): =TIME(A2, B2, C2)

Result: 2:30:00 PM (serial 0.604166666666667)

DATEVALUE​

Convert date text to a date serial value.

Signature: DATEVALUE(date_text)

Sample input

AB
1Date text
23/15/2024

Formula (cell B2): =DATEVALUE(A2)

Result: 45366 (displays as 3/15/2024 when formatted as a date)

TIMEVALUE​

Convert time text to a time serial value.

Signature: TIMEVALUE(time_text)

Sample input

AB
1Time text
22:30 PM

Formula (cell B2): =TIMEVALUE(A2)

Result: 0.604166666666667

DAY​

Extract the day of the month.

Signature: DAY(serial_number)

Sample input

AB
1Project kickoff
23/15/2024

Formula (cell B2): =DAY(A2)

Result: 15

MONTH​

Extract the month number.

Signature: MONTH(serial_number)

Sample input

AB
1Project kickoff
23/15/2024

Formula (cell B2): =MONTH(A2)

Result: 3

YEAR​

Extract the year.

Signature: YEAR(serial_number)

Sample input

AB
1Project kickoff
23/15/2024

Formula (cell B2): =YEAR(A2)

Result: 2024

HOUR​

Extract the hour (0–23).

Signature: HOUR(serial_number)

Sample input

AB
1Shift start
22:30:45 PM

Formula (cell B2): =HOUR(A2)

Result: 14

MINUTE​

Extract the minute.

Signature: MINUTE(serial_number)

Sample input

AB
1Shift start
22:30:45 PM

Formula (cell B2): =MINUTE(A2)

Result: 30

SECOND​

Extract the second.

Signature: SECOND(serial_number)

Sample input

AB
1Shift start
22:30:45 PM

Formula (cell B2): =SECOND(A2)

Result: 45

WEEKDAY​

Return the day-of-week number (default: Sunday = 1 … Saturday = 7).

Signature: WEEKDAY(serial_number, [return_type])

Sample input

AB
1Meeting
23/15/2024

Formula (cell B2): =WEEKDAY(A2)

Result: 6 (Friday)

WEEKNUM​

Return the week number of a year (default week begins Sunday).

Signature: WEEKNUM(serial_number, [return_type])

Sample input

AB
1Meeting
21/7/2024

Formula (cell B2): =WEEKNUM(A2)

Result: 2

ISOWEEKNUM​

Return the ISO week number (weeks start Monday; week 1 contains the year’s first Thursday).

Signature: ISOWEEKNUM(serial_number)

Sample input

AB
1Meeting
23/15/2024

Formula (cell B2): =ISOWEEKNUM(A2)

Result: 11

EDATE​

Move a date by a specified number of months.

Signature: EDATE(start_date, months)

Sample input

AB
1StartMonths
21/31/20241

Formula (cell C2): =EDATE(A2, B2)

Result: 2/29/2024

EOMONTH​

Return the last day of a month offset from a start date.

Signature: EOMONTH(start_date, months)

Sample input

AB
1Invoice dateMonths ahead
21/15/20241

Formula (cell C2): =EOMONTH(A2, B2)

Result: 2/29/2024

DAYS​

Return the number of days between two dates (end − start).

Signature: DAYS(end_date, start_date)

Sample input

AB
1Sprint startSprint end
23/1/20243/15/2024

Formula (cell C2): =DAYS(B2, A2)

Result: 14

DATEDIF​

Return complete years, months, or days between dates ("Y", "M", or "D").

Signature: DATEDIF(start_date, end_date, unit)

Sample input

AB
1Hire dateAs of
21/15/20203/15/2024

Formula (cell C2): =DATEDIF(A2, B2, "Y")

Result: 4

DAYS360​

Calculate days using a 360-day financial year (US NASD method by default).

Signature: DAYS360(start_date, end_date, [method])

Sample input

AB
1Period startPeriod end
21/1/20247/1/2024

Formula (cell C2): =DAYS360(A2, B2)

Result: 180

YEARFRAC​

Return the fraction of a year between two dates (basis 0 = 30/360 US).

Signature: YEARFRAC(start_date, end_date, [basis])

Sample input

AB
1Period startPeriod end
21/1/20247/1/2024

Formula (cell C2): =YEARFRAC(A2, B2, 0)

Result: 0.5

WORKDAY​

Add working days to a date (skips Saturday and Sunday; optional holidays).

Signature: WORKDAY(start_date, days, [holidays])

Sample input

AB
1Start (Mon)Workdays
23/4/20245

Formula (cell C2): =WORKDAY(A2, B2)

Result: 3/11/2024

WORKDAY.INTL​

Add working days using custom weekend rules (1 = Sat/Sun weekend).

Signature: WORKDAY.INTL(start_date, days, [weekend], [holidays])

Sample input

AB
1Start (Mon)Workdays
23/4/20245

Formula (cell C2): =WORKDAY.INTL(A2, B2, 1)

Result: 3/11/2024

NETWORKDAYS​

Count working days between two dates (inclusive; skips Sat/Sun).

Signature: NETWORKDAYS(start_date, end_date, [holidays])

Sample input

AB
1Week startWeek end
23/4/20243/8/2024

Formula (cell C2): =NETWORKDAYS(A2, B2)

Result: 5

NETWORKDAYS.INTL​

Count working days using custom weekend rules (1 = Sat/Sun weekend).

Signature: NETWORKDAYS.INTL(start_date, end_date, [weekend], [holidays])

Sample input

AB
1Week startWeek end
23/4/20243/8/2024

Formula (cell C2): =NETWORKDAYS.INTL(A2, B2, 1)

Result: 5
