Calc Essentials

Everyday arithmetic, totals, powers, and number operations — always available in Core.

Core pack — always on.

Each function below shows Sample input → Formula → Result (or Illustrative result when values can vary).

Functions​

SUM​

Add all numbers in a range or argument list.

Signature: SUM(number...)

Sample input

AB
1ItemAmount
2Coffee4.5
3Tea3.0

Formula (cell C2): =SUM(B2:B3)

Result: 7.5

PRODUCT​

Multiply all numbers.

Signature: PRODUCT(number...)

Sample input

AB
1Unit priceQty
24.53

Formula (cell C2): =PRODUCT(A2, B2)

Result: 13.5

SUMPRODUCT​

Sum of products of corresponding arrays.

Signature: SUMPRODUCT(array...)

Sample input

AB
1PriceQty
24.52
33.01

Formula (cell C2): =SUMPRODUCT(A2:A3, B2:B3)

Result: 12

SUBTOTAL​

Calculate a summary that can respect filters and hidden rows (function code 9 = SUM).

Signature: SUBTOTAL(function_num, ref...)

Sample input

AB
1ItemAmount
2Latte5.0
3Muffin3.5
4Tea2.5

Formula (cell C2): =SUBTOTAL(9, B2:B4)

Result: 11

AGGREGATE​

Calculate summaries while optionally ignoring errors or hidden rows (function 9 = SUM, option 0 = ignore nothing).

Signature: AGGREGATE(function_num, options, ref...)

Sample input

AB
1LineTotal
2Invoice 1120
3Invoice 280
4Invoice 350

Formula (cell C2): =AGGREGATE(9, 0, B2:B4)

Result: 250

ABS​

Absolute value.

Signature: ABS(number)

Sample input

AB
1AccountBalance change
2Tips float-12.5

Formula (cell C2): =ABS(B2)

Result: 12.5

SIGN​

Sign of a number (-1, 0, or 1).

Signature: SIGN(number)

Sample input

AB
1MetricDelta
2Net tips-12.5

Formula (cell C2): =SIGN(B2)

Result: -1

MOD​

Remainder after division.

Signature: MOD(number, divisor)

Sample input

AB
1GuestsTable size
2175

Formula (cell C2): =MOD(A2, B2)

Result: 2

QUOTIENT​

Return the integer portion of a division (truncates toward zero).

Signature: QUOTIENT(numerator, denominator)

Sample input

AB
1GuestsSeats per table
2175

Formula (cell C2): =QUOTIENT(A2, B2)

Result: 3

POWER​

Raise a number to a power.

Signature: POWER(number, power)

Sample input

AB
1BaseExponent
2210

Formula (cell C2): =POWER(A2, B2)

Result: 1024

SQRT​

Square root.

Signature: SQRT(number)

Sample input

AB
1Area (sq ft)
2144

Formula (cell B2): =SQRT(A2)

Result: 12

SQRTPI​

Return the square root of a number multiplied by π (√(n × π)).

Signature: SQRTPI(number)

Sample input

AB
1n
21

Formula (cell B2): =SQRTPI(A2)

Result: 1.77245385090552

PI​

Return the value of π.

Signature: PI()

Sample input

(none — literal call)

Formula (cell A1): =PI()

Result: 3.14159265358979

EXP​

e raised to a power.

Signature: EXP(number)

Sample input

AB
1Rate factor
21

Formula (cell B2): =EXP(A2)

Result: 2.71828182845905

LN​

Natural logarithm (base e).

Signature: LN(number)

Sample input

AB
1Value
22.71828182845905

Formula (cell B2): =LN(A2)

Result: 1

LOG​

Logarithm to a given base (default 10).

Signature: LOG(number, [base])

Sample input

AB
1ValueBase
282

Formula (cell C2): =LOG(A2, B2)

Result: 3

LOG10​

Base-10 logarithm.

Signature: LOG10(number)

Sample input

AB
1Sales
21000

Formula (cell B2): =LOG10(A2)

Result: 3

GCD​

Return the greatest common divisor.

Signature: GCD(number...)

Sample input

AB
1Pack APack B
22436

Formula (cell C2): =GCD(A2, B2)

Result: 12

LCM​

Return the least common multiple.

Signature: LCM(number...)

Sample input

AB
1Shift A daysShift B days
246

Formula (cell C2): =LCM(A2, B2)

Result: 12

FACT​

Return the factorial of a number.

Signature: FACT(number)

Sample input

AB
1Staff on rota
25

Formula (cell B2): =FACT(A2)

Result: 120

FACTDOUBLE​

Return the double factorial of a number (n!!).

Signature: FACTDOUBLE(number)

Sample input

AB
1n
27

Formula (cell B2): =FACTDOUBLE(A2)

Result: 105

COMBIN​

Return combinations without repetition (n choose k).

Signature: COMBIN(n, k)

Sample input

AB
1Menu itemsPick
283

Formula (cell C2): =COMBIN(A2, B2)

Result: 56

COMBINA​

Return combinations with repetition.

Signature: COMBINA(n, k)

Sample input

AB
1ToppingsChoose
242

Formula (cell C2): =COMBINA(A2, B2)

Result: 10

PERMUT​

Return permutations without repetition.

Signature: PERMUT(n, k)

Sample input

AB
1CandidatesSlots
253

Formula (cell C2): =PERMUT(A2, B2)

Result: 60

PERMUTATIONA​

Return permutations with repetition.

Signature: PERMUTATIONA(n, k)

Sample input

AB
1PIN digitsLength
253

Formula (cell C2): =PERMUTATIONA(A2, B2)

Result: 125

SERIESSUM​

Calculate the sum of a power series: a₁xⁿ + a₂xⁿ⁺ᵐ + a₃xⁿ⁺²ᵐ + ….

Signature: SERIESSUM(x, n, m, coefficients)

Sample input

AB
1Coeff
21
31
40.5
50.166666666666667

Formula (cell C2): =SERIESSUM(2, 0, 1, A2:A5)

Result: 6.33333333333333

ROMAN​

Convert an Arabic number to Roman numerals.

Signature: ROMAN(number, [form])

Sample input

AB
1Edition
21999

Formula (cell B2): =ROMAN(A2)

Result: MCMXCIX

ARABIC​

Convert Roman numerals to an Arabic number.

Signature: ARABIC(text)

Sample input

AB
1Roman
2MCMXCIX

Formula (cell B2): =ARABIC(A2)

Result: 1999

RAND​

Return a random decimal between 0 and 1.

Signature: RAND()

Sample input

(none — volatile)

Formula (cell A1): =RAND()

Illustrative result: 0.372814 (varies on each recalculation)

RANDBETWEEN​

Return a random integer between two limits (inclusive).

Signature: RANDBETWEEN(bottom, top)

Sample input

AB
1Min tipMax tip
216

Formula (cell C2): =RANDBETWEEN(A2, B2)

Illustrative result: 4 (integer from 1 through 6; varies on each recalculation)

SUMIF​

Conditional sum.

Signature: SUMIF(range, criteria, [sum_range])

Sample input

AB
1CategoryAmount
2Drink4.5
3Food6.0
4Drink3.0

Formula (cell C2): =SUMIF(A2:A4, "Drink", B2:B4)

Result: 7.5

SUMIFS​

Multi-criteria sum.

Signature: SUMIFS(sum_range, criteria_range1, criteria1, ...)

Sample input

ABC
1CategoryShiftAmount
2DrinkAM4.5
3FoodAM6.0
4DrinkPM3.0
5DrinkAM2.5

Formula (cell D2): =SUMIFS(C2:C5, A2:A5, "Drink", B2:B5, "AM")

Result: 7
