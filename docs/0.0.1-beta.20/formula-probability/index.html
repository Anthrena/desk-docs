Probability Lab

Distribution, inverse, and hypothesis-test formulas for probability work.

Pro Advanced pack — install Probability Lab. Pack off → #PACK?.

Each function below shows Sample input → Formula → Result.

Functions​

NORM.DIST​

Return the normal distribution. Use cumulative=TRUE for the CDF and FALSE for the PDF.

Signature: NORM.DIST(x, mean, standard_dev, cumulative)

Sample input

ABC
1xMeanStdev
242401.5

Formula (cell D2): =NORM.DIST(A2, B2, C2, TRUE)

Result: 0.90878878

With FALSE (PDF): 0.10934005
