Scientific Math

Trigonometry, hyperbolic functions, and angle conversion.

Pro Advanced pack — install Scientific Math. Pack off → #PACK?.

Each function below shows Sample input → Formula → Result.

Functions​

SIN​

Return the sine of an angle (radians).

Signature: SIN(number)

Sample input

(literals in the formula — radians)

Formula (cell C2): =SIN(PI()/2)

Result: 1

COS​

Return the cosine of an angle (radians).

Signature: COS(number)

Sample input

(literals in the formula — radians)

Formula (cell C2): =COS(PI()/3)

Result: 0.5

ATAN2​

Return an angle from x and y coordinates (radians). Excel argument order: ATAN2(x_num, y_num).

Signature: ATAN2(x_num, y_num)

Sample input

AB
1xy
211

Formula (cell C2): =ATAN2(A2, B2)

Result: 0.78539816
