Getting started

Welcome to Anthrena Desk — a desktop analytics workbook for exploring data, building charts, and composing multi-page reports. Everything stays on your machine unless you connect to a database you choose.

Install and launch​

  1. Install the Desk package for your platform (macOS .dmg, Windows installer, or Linux package from your IT team).
  2. Open Anthrena Desk. A brief splash screen appears while the app loads.
  3. On first launch, a compact Welcome window appears (same size family as the splash). Choose Start with a sample workbook, Create, or Open — no account required.
  4. The main Studio window then shows the report canvas (or your sample / opened workbook).

Returning launches skip Welcome and go splash → main when you have already completed Welcome or recently opened a workbook.

Sign in from Welcome (Sync row) or the title-bar Free/Pro chip opens a compact Account window for identity and plans — not a full-screen login wall.

Open, save, and close workbooks​

Desk workbooks use the .asbx format (layout + embedded data).

ActionShortcut (macOS)Notes
New worksheet⌘NBlank in-memory sheet; opens Data view
Open⌘OFile picker for .asbx
Open Recent—Last 10 workbooks
Save⌘SOverwrites current path, or Save As on first save
Save As⇧⌘SChoose folder and name
Close⌘WUnsaved guard, then blank sheet

You can also double-click an .asbx file in Finder (or your OS file manager) to open it.

Autosave and recovery​

If Desk quits unexpectedly, it keeps a crash autosave under your application support folder. On next launch you may see a recovery prompt — restore the autosaved workbook or discard it and continue. Desk may also offer an optional crash report (Settings → Privacy); nothing is sent unless you choose Send.

Autosave does not replace intentional Save (⌘S). Save regularly when collaborating or shipping a file.

Free vs Pro​

Desk runs on a Free plan by default:

  • Import files and build reports
  • Save .asbx workbooks
  • Up to 50,000 rows per dataset

Pro unlocks database connectors, PDF export, plugin install, and unlimited rows. See Licensing.

tip

Save early with ⌘S — autosave is only a crash safety net, not a substitute for Save.
