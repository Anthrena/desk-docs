Statistical Summary

Counts, averages, ranks, percentiles, and descriptive statistics.

Pro plugin pack — install Statistical Summary. Pack off → #PACK?.

Each function below shows Sample input → Formula → Result.

Functions​

COUNT​

Count numeric cells.

Signature: COUNT(value...)

Sample input

ABC
1RegionItemSales
2NorthLatte120
3SouthMocha95
4NorthEspresso140
5WestLatte110
6SouthLatte80
7NorthMocha130

Formula (cell E2): =COUNT(C2:C7)

Result: 6

Count non-empty cells.

Signature: COUNTA(value...)

Sample input

3Mocha
4Espresso15

RANK.EQ​

Rank a value with equal values sharing the same rank.

Signature: RANK.EQ(number, ref, [order])

Sample input

ABC
1RegionItemSales
2NorthLatte120
3SouthMocha95
4NorthEspresso140
5WestLatte110
6SouthLatte80
7NorthMocha130

Formula (cell E2): =RANK.EQ(120, C2:C7)

Result: 3 (descending; ties share the same rank)

RANK.AVG​

Result: 2.5 (both 110 values share average rank)
