Markets & Securities

Bond price/yield, duration, accrued interest, T-bills, and coupon helpers.

Pro Advanced pack — install Markets & Securities. Pack off → #PACK?.

Each function below shows Sample input → Formula → Result (Excel-compatible settlement / maturity / coupon examples). Prices per $100 face value round to 2–5 decimals; yields to 4–6 decimals.

Day-count basis: 0 = US 30/360, 1 = actual/actual, 2 = actual/360, 3 = actual/365, 4 = European 30/360. Prefer DATE(y,m,d) (or date cells) rather than raw serials.

Functions​

PRICE​

Return the price of a coupon-paying security.

Signature: PRICE(settlement, maturity, rate, yld, redemption, frequency, [basis])

Sample input

AB
1Settlement2008-02-15
2Maturity2017-11-15
3Coupon rate0.0575
4Yield0.065
5Redemption100
6Frequency (semiannual)2
7Basis (30/360)0

Formula (cell C2): =PRICE(DATE(2008,2,15), DATE(2017,11,15), B3, B4, B5, B6, B7)

Result: 94.63436 (price per $100 face value)
