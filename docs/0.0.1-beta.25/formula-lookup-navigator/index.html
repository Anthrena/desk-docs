Lookup Navigator

Find related values with XLOOKUP, INDEX/MATCH, and classic lookups.

Core pack — always on.

Each function below shows Sample input → Formula → Result (or Illustrative result when values can vary).

Functions​

XLOOKUP​

Find a value and return a related value from another range.

Signature: XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])

Sample input

ABC
1SKUProductPrice
2SKU-100Mug12.5
3SKU-200Bottle18.0
4SKU-300Tote24.0

Formula (cell E2): =XLOOKUP("SKU-200",A2:A4,C2:C4)

Result: 18

(Exact match is the default; prefer XLOOKUP over VLOOKUP when available.)

XMATCH​

Return the relative position of a matching value.

Signature: XMATCH(lookup_value, lookup_array, [match_mode], [search_mode])

Sample input

AB
1SKU
2SKU-100
3SKU-200
4SKU-300

Formula (cell B2): =XMATCH("SKU-300",A2:A4)

Result: 3

VLOOKUP​

Vertical lookup. Use FALSE for exact; TRUE requires sorted keys (unsorted → #VALUE!). Prefer XLOOKUP.

Signature: VLOOKUP(lookup, table, col_index, [range_lookup])

Sample input

ABC
1SKUProductPrice
2SKU-100Mug12.5
3SKU-200Bottle18.0
4SKU-300Tote24.0

Formula (cell E2): =VLOOKUP("SKU-100",A2:C4,3,FALSE)

Result: 12.5

(FALSE forces exact match. Approximate match needs sorted first-column keys.)

HLOOKUP​

Horizontal lookup. Use FALSE for exact; TRUE requires sorted keys (unsorted → #VALUE!). Prefer XLOOKUP.

Signature: HLOOKUP(lookup, table, row_index, [range_lookup])

Sample input

ABCD
1FieldSKU-100SKU-200SKU-300
2Price12.518.024.0
3Stock40128

Formula (cell A5): =HLOOKUP("SKU-200",A1:D3,2,FALSE)

Result: 18

LOOKUP​

Perform an approximate lookup in a row or column.

Signature: LOOKUP(lookup_value, lookup_vector, [result_vector])

Sample input

AB
1QtyTier
20Bronze
350Silver
4100Gold

Formula (cell C2): =LOOKUP(75,A2:A4,B2:B4)

Result: Silver

(Vector form finds the largest value ≤ lookup in a sorted ascending vector.)

INDEX​

Return a value at a specified row and column position.

Signature: INDEX(array, row_num, [column_num])

Sample input

ABC
1SKUProductPrice
2SKU-100Mug12.5
3SKU-200Bottle18.0
4SKU-300Tote24.0

Formula (cell E2): =INDEX(A2:C4,2,2)

Result: Bottle

MATCH​

Return the position of a matching item.

Signature: MATCH(lookup_value, lookup_array, [match_type])

Sample input

AB
1SKU
2SKU-100
3SKU-200
4SKU-300

Formula (cell B2): =MATCH("SKU-200",A2:A4,0)

Result: 2

(0 is exact match.)

ADDRESS​

Create a cell address as text.

Signature: ADDRESS(row, column, [abs_num], [a1], [sheet])

Sample input

AB
1RowCol
232

Formula (cell C2): =ADDRESS(A2,B2)

Result: $B$3

ROW​

Return a reference's row number.

Signature: ROW([reference])

Sample input

AB
1SKUPrice
2SKU-10012.5
3SKU-20018.0

Formula (cell C3): =ROW(A3)

Result: 3

ROWS​

Count rows in a reference.

Signature: ROWS(array)

Sample input

AB
1SKUPrice
2SKU-10012.5
3SKU-20018.0
4SKU-30024.0

Formula (cell C2): =ROWS(A2:B4)

Result: 3

COLUMN​

Return a reference's column number.

Signature: COLUMN([reference])

Sample input

ABC
1SKUProductPrice
2SKU-100Mug12.5

Formula (cell D2): =COLUMN(C2)

Result: 3

COLUMNS​

Count columns in a reference.

Signature: COLUMNS(array)

Sample input

ABC
1SKUProductPrice
2SKU-100Mug12.5

Formula (cell D2): =COLUMNS(A1:C2)

Result: 3

CHOOSE​

Select one value from a list by index.

Signature: CHOOSE(index_num, value1, [value2], …)

Sample input

AB
1Region code
22

Formula (cell B2): =CHOOSE(A2,"North","South","East","West")

Result: South

AREAS​

Count separate areas in a reference.

Signature: AREAS(reference)

Sample input

ABC
1SKUPriceExtra
2SKU-10012.51
3SKU-20018.02

Formula (cell D2): =AREAS(A2:B3)

Result: 1

(A single contiguous range is one area. Multi-area refs like (A2:A3,C2:C3) return 2.)
