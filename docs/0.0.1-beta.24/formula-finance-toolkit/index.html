Finance Toolkit

Loans, NPV/IRR, depreciation, and cash-flow math for finance models.

Pro plugin pack — install Finance Toolkit from Preferences → Plugins. Pack off → #PACK?.

Each function below shows Sample input → Formula → Result (Excel-compatible cash-flow / loan / depreciation examples). Currency results round to 2 decimals; rates to 4–6 decimals where useful.

Functions​

PMT​

Calculate a periodic loan or investment payment.

Signature: PMT(rate, nper, pv, [fv], [type])

Sample input

AB
1Annual rate0.05
2Term (years)30
3Loan principal200000

Formula (cell C2): =PMT(B1/12, B2*12, B3)

Result: -1073.64 (monthly payment; negative = cash you pay out)

PV​

Calculate present value.

Signature: PV(rate, nper, pmt, [fv], [type])

Sample input

AB
1Rate per period0.08
2Periods10
3Payment100

Formula (cell C2): =PV(B1, B2, B3)

Result: -671.01 (present value of ten $100 payments at 8%)

FV​

Calculate future value.

Signature: FV(rate, nper, pmt, [pv], [type])

Sample input

AB
1Rate per period0.08
2Periods10
3Payment-100

Formula (cell C2): =FV(B1, B2, B3)

Result: 1448.66 (future value of ten deposits of $100 at 8%)

NPV​

Calculate net present value for periodic cash flows.

Signature: NPV(rate, value1, [value2], …)

Sample input

AB
1Discount rate0.1
2Year 1 cash flow100
3Year 2 cash flow200
4Year 3 cash flow300

Formula (cell C2): =NPV(B1, B2:B4)

Result: 481.59 (Excel NPV discounts the first value as period 1)

XNPV​

Calculate net present value for irregularly dated cash flows.

Signature: XNPV(rate, values, dates)

Sample input

AB
1Discount rate0.09
22008-01-01-10000
32008-03-012750
42008-10-304250
52009-02-153250
62009-04-012750

Formula (cell C2): =XNPV(B1, B2:B6, A2:A6)

Result: 2086.65 (ACT/365 day count)

IRR​

Calculate internal rate of return for periodic cash flows.

Signature: IRR(values, [guess])

Sample input

AB
1Initial outlay-70000
2Year 112000
3Year 215000
4Year 318000
5Year 421000
6Year 526000

Formula (cell C2): =IRR(B1:B6)

Result: 0.0866 (8.66% per period)

XIRR​

Calculate internal rate of return for irregularly dated cash flows.

Signature: XIRR(values, dates, [guess])

Sample input

AB
12008-01-01-10000
22008-03-012750
32008-10-304250
42009-02-153250
52009-04-012750

Formula (cell C2): =XIRR(B1:B5, A1:A5)

Result: 0.3734 (37.34% annualized)

RATE​

Calculate the interest rate per period.

Signature: RATE(nper, pmt, pv, [fv], [type], [guess])

Sample input

AB
1Periods (months)48
2Payment-200
3Present value (loan)8000

Formula (cell C2): =RATE(B1, B2, B3)

Result: 0.0077 (0.77% per month ≈ 9.24% APR)

NPER​

Calculate the number of payment periods.

Signature: NPER(rate, pmt, pv, [fv], [type])

Sample input

AB
1Monthly rate0.05/12
2Payment-100
3Loan5000

Formula (cell C2): =NPER(B1, B2, B3)

Result: 56.18 (about 56 months to pay off)

IPMT​

Return the interest portion of a payment.

Signature: IPMT(rate, per, nper, pv, [fv], [type])

Sample input

AB
1Monthly rate0.1/12
2Period1
3Term (months)36
4Loan80000

Formula (cell C2): =IPMT(B1, B2, B3, B4)

Result: -666.67 (interest in the first payment)

PPMT​

Return the principal portion of a payment.

Signature: PPMT(rate, per, nper, pv, [fv], [type])

Sample input

AB
1Monthly rate0.1/12
2Period1
3Term (months)36
4Loan80000

Formula (cell C2): =PPMT(B1, B2, B3, B4)

Result: -1914.71 (principal in the first payment; IPMT + PPMT = PMT)

CUMIPMT​

Return cumulative interest paid.

Signature: CUMIPMT(rate, nper, pv, start_period, end_period, type)

Sample input

AB
1Monthly rate0.09/12
2Term (months)360
3Loan125000
4Start period13
5End period24
6Type (end of period)0

Formula (cell C2): =CUMIPMT(B1, B2, B3, B4, B5, B6)

Result: -11135.23 (interest paid in year 2 of a 30-year mortgage)

CUMPRINC​

Return cumulative principal paid.

Signature: CUMPRINC(rate, nper, pv, start_period, end_period, type)

Sample input

AB
1Monthly rate0.09/12
2Term (months)360
3Loan125000
4Start period13
5End period24
6Type (end of period)0

Formula (cell C2): =CUMPRINC(B1, B2, B3, B4, B5, B6)

Result: -934.11 (principal repaid in year 2)

EFFECT​

Return the effective annual interest rate.

Signature: EFFECT(nominal_rate, npery)

Sample input

AB
1Nominal annual rate0.0525
2Compounds per year4

Formula (cell C2): =EFFECT(B1, B2)

Result: 0.053543 (5.3543% effective)

NOMINAL​

Return the nominal annual interest rate.

Signature: NOMINAL(effect_rate, npery)

Sample input

AB
1Effective annual rate0.0535427
2Compounds per year4

Formula (cell C2): =NOMINAL(B1, B2)

Result: 0.0525 (5.25% nominal)

RRI​

Return an equivalent growth rate.

Signature: RRI(nper, pv, fv)

Sample input

AB
1Periods5
2Present value100
3Future value200

Formula (cell C2): =RRI(B1, B2, B3)

Result: 0.148698 (≈14.87% per period to double in 5 periods)

PDURATION​

Return periods required for an investment to reach a value.

Signature: PDURATION(rate, pv, fv)

Sample input

AB
1Rate per period0.1
2Present value100
3Future value200

Formula (cell C2): =PDURATION(B1, B2, B3)

Result: 7.2725 (periods to double at 10%)

SLN​

Calculate straight-line depreciation.

Signature: SLN(cost, salvage, life)

Sample input

AB
1Cost30000
2Salvage7500
3Life (years)10

Formula (cell C2): =SLN(B1, B2, B3)

Result: 2250.00 (same depreciation each year)

SYD​

Calculate sum-of-years-digits depreciation.

Signature: SYD(cost, salvage, life, per)

Sample input

AB
1Cost30000
2Salvage7500
3Life (years)10
4Period1

Formula (cell C2): =SYD(B1, B2, B3, B4)

Result: 4090.91 (year-1 SYD depreciation)

DB​

Calculate fixed-declining balance depreciation.

Signature: DB(cost, salvage, life, period, [month])

Sample input

AB
1Cost1000000
2Salvage100000
3Life (years)6
4Period1

Formula (cell C2): =DB(B1, B2, B3, B4)

Result: 319000.00 (first full year; declining-balance factor 0.319)

DDB​

Calculate double-declining balance depreciation.

Signature: DDB(cost, salvage, life, period, [factor])

Sample input

AB
1Cost2400
2Salvage300
3Life (years)10
4Period1

Formula (cell C2): =DDB(B1, B2, B3, B4)

Result: 480.00 (first-year double-declining balance)

VDB​

Calculate variable declining balance depreciation.

Signature: VDB(cost, salvage, life, start_period, end_period, [factor], [no_switch])

Sample input

AB
1Cost2400
2Salvage300
3Life (years)10
4Start period0
5End period1

Formula (cell C2): =VDB(B1, B2, B3, B4, B5)

Result: 480.00 (depreciation from the start of year 1 through the end of year 1)

AMORDEGRC​

Calculate prorated depreciation using French accounting rules.

Signature: AMORDEGRC(cost, date_purchased, first_period, salvage, period, rate, [basis])

Sample input

AB
1Cost2400
2Purchased2008-08-19
3First period end2008-12-31
4Salvage300
5Period1
6Rate0.15
7Basis (actual/actual)1

Formula (cell C2): =AMORDEGRC(B1, DATE(2008,8,19), DATE(2008,12,31), B4, B5, B6, B7)

Result: 776 (French declining coefficient applied to period 1)

AMORLINC​

Calculate linear depreciation by accounting period.

Signature: AMORLINC(cost, date_purchased, first_period, salvage, period, rate, [basis])

Sample input

AB
1Cost2400
2Purchased2008-08-19
3First period end2008-12-31
4Salvage300
5Period1
6Rate0.15
7Basis (actual/actual)1

Formula (cell C2): =AMORLINC(B1, DATE(2008,8,19), DATE(2008,12,31), B4, B5, B6, B7)

Result: 360 (linear French accounting depreciation for period 1)

MIRR​

Calculate modified internal rate of return.

Signature: MIRR(values, finance_rate, reinvest_rate)

Sample input

AB
1Initial outlay-120000
2Year 139000
3Year 230000
4Year 321000
5Year 437000
6Year 546000
7Finance rate0.1
8Reinvest rate0.12

Formula (cell C2): =MIRR(B1:B6, B7, B8)

Result: 0.1261 (12.61% modified IRR)

FVSCHEDULE​

Calculate future value using a series of rates.

Signature: FVSCHEDULE(principal, schedule)

Sample input

AB
1Principal100
2Year 1 rate0.09
3Year 2 rate0.11
4Year 3 rate0.1

Formula (cell C2): =FVSCHEDULE(B1, B2:B4)

Result: 133.09 (100 × 1.09 × 1.11 × 1.10)

ISPMT​

Calculate interest paid during a specified period.

Signature: ISPMT(rate, per, nper, pv)

1Monthly rate0.1/12
2Period1
3Term (months)36
4Loan8000000

Formula (cell C2): =ISPMT(B1, B2, B3, B4)

Result: -64814.81 (interest for period 1 under even principal repayment)
