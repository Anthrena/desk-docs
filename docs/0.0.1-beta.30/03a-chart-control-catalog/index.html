Chart and control catalog

Field wells, Inspector parameters, and supported data types for every built-in Tile on the report Stage. Source of truth: chartCapabilities.ts, tileFieldSlots.ts, canvasControls.ts, dtype.ts, fieldProfile.ts.

Plugins may add extra chart / control types via the plugin registry; this page lists builtins from Insert → Visuals.

Data types​

Desk classifies Fluxor / Polars column labels, then profiles a field kind used by wells and drop-slot suggestions.

temporaldate / datetimeCategory (with date bucket), Compare, Trend, Period
booleanboolCategory / Series / Switch

idhigh-uniqueness string or int (*_id, UUID, …)Prefer Values (count) — Category / Series warn as crowded

Aggregation on Values wells: sum · mean · count · min · max. count works on any dtype; the others need numeric (or a measure SmartField).

Drop rules (all charts unless a well says otherwise):

  • Measures cannot land on Category (axisField) or Series (seriesField), except Geo points Latitude / Longitude.
  • Measures cannot land on Matrix Rows / Columns.
  • Measures cannot land on Metric tree Trend.
  • Dates as Series are blocked (one series per day). Put the date on Category and set a date bucket.
  • IDs on Category / Series show a crowding warning; prefer Values with count.
