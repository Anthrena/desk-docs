Measure formula semantics (Desk / Canvas)

SmartField measures (KPI cards, chart values) evaluate in the Desk/Canvas TS engine, not Fluxor WASM evaluate_smart_field_metric. Fluxor only runs groupby + filter_ast.

Contracts​

FormulaModeSemantics
PCTOFTOTAL(expr)Chart / KPIexpr under current axis by + slicers, divided by the same expr with by cleared (slicers kept).
CALCULATE(expr, …)AnyRe-evaluate expr with modifiers applied.
REMOVEFILTERS()CALCULATEClear visual grouping (by); keep slicer filter_ast.
REMOVEFILTERS(col…)CALCULATEDrop those columns from by and from filter_ast.
col = "x" / col = 1CALCULATEAND an eq clause into filter_ast.
col IN ("a","b")CALCULATEAND an in clause into filter_ast.
COUNTIF / AVERAGEIF / SUMIFSugarRewrites to CALCULATE(COUNT|AVG|SUM(…), criteriaCol = criteria). Same idea as Fluxor sheet AVERAGEIF / SUMIF / COUNTIF, but for measures (chart/KPI).
PREVIOUSPERIOD / SAMEPERIODLASTYEAR / DATESYTD / ROLLINGKPI / cardWindow from max date under current filters (not per chart bar).
PERIODCOMPARE(expr, dateCol, "month"|"year")ChartRequires a period group on the axis. Emits current − prior per group path.

Worked example — Command Centre loan book​

Assume a sheet with these columns:

ColumnExample values
loan_idL1, L2, …
statusSourced, Sanctioned, Disbursed
zoneEast, West, …
application_date2024-01-10
disbursement_date2024-01-18 (null until disbursed)
dpd_bucket0-30, 31-60, 61-90, 90+
outstanding_balancerupee outstanding
emi_due / emi_collectedperiod EMI amounts
call_id / resolved_firstcontact-centre rows (1 = first-call fix)

1. Funnel KPI cards (sourcing)​

Sourced — all loans in scope (slicers still apply):

=COUNT(loan_id)

Sanctioned — status in sanctioned pipeline (includes already disbursed):

=CALCULATE(COUNT(loan_id), status IN ("Sanctioned","Disbursed"))

Disbursed — equality filter (or COUNTIF sugar):

=CALCULATE(COUNT(loan_id), status = "Disbursed")
=COUNTIF(status, "Disbursed", loan_id)

Both COUNTIF and CALCULATE AND with any zone / product slicers already on the report.

Avg amount among disbursed — measure AVERAGEIF (Fluxor sheet/column also has AVERAGEIF for cell formulas):

=AVERAGEIF(status, "Disbursed", amount)
=CALCULATE(AVG(amount), status = "Disbursed")

2. Conversion rates​

Sourced → Sanctioned %

=DIVIDE(
  CALCULATE(COUNT(loan_id), status IN ("Sanctioned","Disbursed")),
  COUNT(loan_id)
)

Sanctioned → Disbursed %

=DIVIDE(
  CALCULATE(COUNT(loan_id), status = "Disbursed"),
  CALCULATE(COUNT(loan_id), status IN ("Sanctioned","Disbursed"))
)

Overall (Disbursed / Sourced)

=DIVIDE(
  CALCULATE(COUNT(loan_id), status = "Disbursed"),
  COUNT(loan_id)
)

Quick measures folder Lending / ops inserts these as conversionSanctioned, conversionDisbursed, conversionOverall (field A = loan_id, field B = status).

3. Turnaround time (TAT)​

Column SmartField (row-level — Fluxor date_diff):

=date_diff(disbursement_date, application_date, "days")

Name it e.g. tat_days. Null when not yet disbursed.

Avg TAT KPI

=AVG(tat_days)

Avg TAT for disbursed only (when tat_days is null for non-disbursed, plain AVG may already skip nulls — otherwise):

=AVERAGEIF(status, "Disbursed", tat_days)

Avg TAT by zone — put zone on the chart Category axis; same measure.

MoM TAT delta on a monthly line chart — group the chart by month of disbursement_date (or a YYYY-MM column), then:

=PERIODCOMPARE(AVG(tat_days), disbursement_date, "month")

Each month bar = this month’s avg TAT minus the previous calendar month’s avg TAT (positive = slower).

MoM % (quick measure momPct pattern):

=DIVIDE(
  PERIODCOMPARE(AVG(tat_days), disbursement_date, "month"),
  AVG(tat_days) - PERIODCOMPARE(AVG(tat_days), disbursement_date, "month")
)

Do not use PREVIOUSPERIOD on that monthly chart — it uses the max date in the filtered data as one global window (KPI-card mode), so every bar would share the same prior window.

KPI card “last full month avg TAT” (single number):

=PREVIOUSPERIOD(AVG(tat_days), disbursement_date, "month")

4. Portfolio risk (PAR)​

Prefer amount-weighted when outstanding_balance exists:

=DIVIDE(
  CALCULATE(SUM(outstanding_balance), dpd_bucket IN ("31-60","61-90","90+")),
  SUM(outstanding_balance)
)

Count-weighted demo fallback (loan headcount):

=DIVIDE(
  CALCULATE(COUNT(loan_id), dpd_bucket IN ("31-60","61-90","90+")),
  COUNT(loan_id)
)

Zone stress — same PAR share formula on a chart with Category = zone (ranks East/Central by late-book exposure).

Quick measure: PAR 30+ % / Zone stress (A = balance or id, B = dpd_bucket).

5. Collections & contact centre​

Collections efficiency %

=DIVIDE(SUM(emi_collected), SUM(emi_due))

First-call resolution %

=DIVIDE(
  CALCULATE(COUNT(call_id), resolved_first = 1),
  COUNT(call_id)
)

6. Share of total (zone league)​

On a bar chart Category = zone:

=PCTOFTOTAL(SUM(outstanding_balance))

Or manually:

=DIVIDE(SUM(outstanding_balance), CALCULATE(SUM(outstanding_balance), REMOVEFILTERS()))

Slicers (e.g. product) stay on; only the visual zone grouping is cleared for the denominator.

When to use which time formula​

GoalFormulaChart setup
One KPI: “prior calendar month vs data’s latest date”PREVIOUSPERIOD(…, dateCol, "month")No period axis required
One KPI: YTD through latest dateDATESYTD(…, dateCol)Card
Trend: each month vs previous monthPERIODCOMPARE(…, dateCol, "month")Category / axis = month grain of dateCol
Trend: each year vs prior yearPERIODCOMPARE(…, dateCol, "year")Axis = year
