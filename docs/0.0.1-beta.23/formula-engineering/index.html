Engineering Tools

Unit convert, base conversion, bit ops, complex numbers, and Bessel/erf.

Pro Advanced pack — install Engineering Tools. Pack off → #PACK?.

Each function below shows Sample input → Formula → Result.

Functions​

CONVERT​

Convert a number between measurement units.

Signature: CONVERT(number, from_unit, to_unit)

Sample input

ABC
1ValueFromTo
21mikm

Formula (cell D2): =CONVERT(A2, B2, C2)

Result: 1.609344

Also: =CONVERT(100, "C", "F") → 212 (Celsius to Fahrenheit).
